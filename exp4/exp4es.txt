These response-only fields are:

AA – Authoritative Answer

RA – Recursion Available
RCODE – Response Code

Functions:

TC: Indicates the response was truncated.
RA: Indicates recursion is available.
RCODE: Indicates whether the query succeeded or reports an error (e.g., NXDOMAIN).
